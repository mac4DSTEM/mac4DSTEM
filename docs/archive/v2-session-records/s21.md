## Facts established during scoping

- All harnesses in the `scientific` array are self-contained on a fresh
  checkout: no `$HOME`/`/Volumes` paths, root HDF5 dylibs tracked, committed
  `.h5` fixtures small and tracked, every package `.py` of the vendored
  py4DSTEM tracked (the only untracked `.py` are dev scripts outside the
  package).
- Locally the harnesses import the vendored py4DSTEM source via `PYTHONPATH`
  over a conda env whose *installed* py4DSTEM is 0.14.17 — the source lock
  governs either way; what needed pinning for CI was the numerical stack.
- `python_requires >= 3.10`; local interpreter 3.12.3; CI pins 3.12.

## Gate A — outcome

Four independent finder agents (line-by-line, claims/honesty audit,
cross-file fresh-runner tracer, cleanup+altitude+conventions) + one
independent verifier over the deduped list. **9 findings survived (7
CONFIRMED, 2 PLAUSIBLE), all 9 fixed in-session:**

1. Xcode 26's Metal compiler is a separate downloadable component neither job
   installed (would have killed both jobs on an image without it) — guarded
   install step added to both.
2. `on: push` only — fork PRs would surface zero checks → `pull_request:`
   added.
3. `cancel-in-progress: true` erased in-flight main runs (including the S17
   observations the header says the runner exists to collect) → expression
   spares main.
4. The parity environment floated on ~20 open-lower-bound deps and the pip
   cache key never changed → the constraints file, `-c` install, cache keyed
   on it.
5. Header overclaimed "every one compares against the vendored py4DSTEM
   lock" — false for 13 of 37 harnesses → reworded.
6. The exclusion list silently omitted ui-smoke-test, ui-qc-playthrough,
   acom-groundtruth — against its own "silence is never the reason" banner →
   added.
7. Hard-coded "all 37" would stale on the next added harness → the array is
   named as the roster, no count stated.
8. 90-minute scientific timeout was an unmeasured guess → widened to 180 and
   labeled margin-not-measurement, to be tightened from the first green run's
   per-harness timings.
9. Docs/badge not updated with the change → README badge, CLAUDE.md row,
   open-items entry, this record. (The verifier also settled badge-now vs
   badge-at-S19 from the plan's own rows: the badge lands with S21.)

The cross-file tracer returned zero findings: scheme tracked, `df -Pg` parse
valid, `PYTHON` override satisfies `resolve_mac4dstem_python` (numpy arrives
via install_requires), `vendor-reader-test`'s bare `python3` is stdlib-only,
ad-hoc codesign needs no identity, no network use in any harness.
