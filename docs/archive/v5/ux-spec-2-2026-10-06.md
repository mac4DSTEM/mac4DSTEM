## 1. Decisions taken as the owner's delegate (overrule on sight)

- D-1 **Regions live on the ColorMix only** (his bullet 24). Tiles are pickers: they never carry a region. The "active map" state retires.
- D-2 **A tile's accent outline means "in the ColorMix"** (bullet 7): click toggles it, click again removes it; the HAADF tile toggles the
  HAADF backdrop under the mix (bullet 3). No checkboxes on tiles. Colour / contrast / gamma stay on the tile's chip popover (the app's
  pattern) — the inspector's Map display section goes.
- D-3 **Auto ID is a button**, full width in Elements (bullet 18); it runs on open (ADR 056 §6, kept) and APPLIES its picks: the elements
  are picked (Quantify role) and mapped at once; the person removes the wrong ones in the table. "proposed" tiles, the 3-tile cap and
  Accept go. The badge `unvalidated` stands beside the button; the row under it reads "Auto ID picked: Al, Si, Mg" with the reasons,
  sum-peak questions and not-tested list in its hover. Suspect markers ("Tm+Tm sum? (or Ar Kα)") leave the plot (bullet 28).
- D-4 **The quantification panel leaves the content** (bullet 21): the spectrum takes the full width; the table and everything under
  it become the inspector's **Results** section (badge in the section's first row, "· no absorption" in the column header, caveat,
  χ²ᵣ, Method disclosure, whole-map line) — nothing dropped.
- D-5 **Inspector sections**: Elements · Region · Results · Quantification · Fitting · Export. "Expert" is gone (bullet 19, 23):
  Quantification = Background, k-factors, Absorption, Thickness (+σ), Beam energy; Fitting (closed by default) = Estimator, σ_k,
  Poly order (when polynomial), Lock energy axis, Fit to, the energy-axis note. Velox names these "Quantification" and "Fitting".
- D-6 **Spectrum**: log off by default (bullet 2); double-click = the full range (0 to the energy below which 99.5 % of the counts lie,
  at most 20 keV; bullet 9); Home = the lines' span (the opening view); a vertical drag in the y-axis gutter stretches the y scale
  (bullet 9); zoom clamps to the domain and the anchor is taken in plot coordinates (bullet 10).
- D-7 **Two dividers** (bullets 8, 16): the spectrum's header row is the drag handle between the maps block and the spectrum (the
  infobar pattern, `StatusBar`), from "maps only" to "spectrum only"; a 9-pt grab zone between the ColorMix and the tile column sets
  the ColorMix width. Both are scene state (`@SceneStorage`), not method state.
- D-8 **Glass**: only where Apple puts it over media — the capsules on maps (scale bar, region label, the empty-mix hint) use
  `.glassEffect(.regular, in: .capsule)`; nothing else in the room gets glass (HIG Materials). Shell glass: §4.
- D-9 **Periodic table in the table's own shape** (bullet 4): 18 columns, periods 1–6, the f-block and period 7 folded as today;
  cells scale with the inspector's width (cell = (width − 17·gap) / 18, gap 2), symbols at 0.5 × cell clamped 9–13 pt. At the
  narrowest content column (248 pt) a cell is 13.9 pt; the inspector widens by drag. A wider default = §4.
- D-10 **Right-click an element** (bullet 15): Quantify / Fit only / Off, then "Lines" listing each family with its lines and energies
  ("K · Kα 1.487 · Kβ 1.557 keV"). Picking single lines changes the fit model (a science registration), not tonight.
- D-11 **Lineage** (bullet 27): the quantification step's provenance is written as readable keys (background, k_factors, absorption,
  estimator, fit_range_kev, elements, region) plus one short `method` hash; the JSON blob goes. The hash row leaves the Export section.
- D-12 **Quantify runs as an operation** (bullet 12): through `AppState.beginCancellableOperation`, so the infobar shows the bar,
  elapsed and Stop like every other verb. The Auto ID run too.
- D-13 **Histogram** (bullet 11): the shared `HistogramView` shows real values when the caller supplies a scale and unit (net counts for
  element maps, the HAADF's own unit); the min / max readouts are editable (click → field, commit on Return), gamma unchanged.
- D-14 **Export once** (bullet 22): the inspector's Export section only — Elements row, "Results CSV…", "Method JSON…", and
  "Spectrum CSV…" (the shown spectrum: energy, counts, model, background when fitted), the last one available whenever a spectrum is
  shown, so an EMD opened alone can still hand its spectrum out (bullet 25, the part that is UI). Products in the Results room: §4.
- D-15 **Highlight** (bullet 13): clicking or hovering an element tile (or a periodic-table cell) sets `highlightedZ`; its line markers
  draw at 2× width with their labels bold while highlighted. A click still toggles the mix (D-2).
- D-16 **Region editing** (bullet 14): rectangle (default), ellipse, polygon in the inspector's Region row "Tool"; a drag on the
  ColorMix draws, inside moves, a handle resizes; ⌫ deletes the live region, ⎋ cancels a polygon draft; a polygon closes on its first
  corner or on double-click. The "Region · n px · live" capsule stays. One live region + up to three pins (ADR 056 addendum).
