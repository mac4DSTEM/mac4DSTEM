  1. 1
    It lives in the bottom Lineage pane. This is the debug-area slot from ADR 034, and the owner asked for "Output + a lineage graph, side by side". The graph replaces today's chain. No Frozen Shell file changes and no new window. The inspector keeps the room's settings. Results gets the plain lineage list in L2.
  2. 2
    Edges are inputs that were actually consumed, laid out left to right. Strain, ACOM and Phases all read the same disk detection. The graph shows only direct edges: Phases also read Q scale, but that edge is already implied through Disks, so it shows when the node is selected. CIFs are external inputs, listed in the detail by name and fingerprint.
  3. 3
    A rewind followed by a run makes a branch; nothing is deleted. Rewinding to Q scale and detecting again at 0.15 % started the top path. The 0.50 % run and everything built on it stay below it, dimmed. A re-run with the same inputs that nothing depends on replaces its node instead, so moving a slider back and forth does not grow the graph.
  4. 4
    Status is shown by a symbol, not by colouring the node. Boxes stay neutral. Colour is only on the check and the warning triangle, and the accent is only on the selection (inspector HIG). The dashed ACOM means its settings are active, but the map on screen was computed on the other branch (s6), so it is stale until it runs again.
  5. 5
    Clicking a node shows its record in a column inside the pane: the difference from the active path, the parameters (label left, value right), the inputs, and one bordered Rewind to Here button. The toolbar's run button stays the only prominent one. The sentence under the button says exactly what will become current or stale before you click. Arrow keys move between nodes, and the column stays open while you do.

Considered, not recommended

  • An inspector tab. The inspector holds the room's settings (ADR 034) and is Frozen Shell.
  • A Results tab. It is far from the work. It gets the L2 list, not the graph.
  • A popover per node. It closes when you move to the next node, so you cannot step through a branch while comparing parameters.
  • Deleting downstream on rewind. This cannot be undone, and one ACOM run can take an hour.
  • Recomputing on rewind. A long run would start from what looks like navigation. In L4, re-running is its own explicit step.
