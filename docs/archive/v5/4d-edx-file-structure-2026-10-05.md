# Simultaneous 4D-STEM + EDX on disk: report (2026-10-05)
Marks: VERIFIED = seen in a file / source code I read; WEB = published statement; INFERRED = reasoning; GUESS = invented for the simulator.
Scratch: $SP/fmt4dedx/ (dump.py, rng.py, ranged_dump.txt, dl/).

## 0. Headline
1. No public GMS file holds 4D + EDS in ONE .dm4. The one real GMS EDS-with-Super-X file is a 1D spectrum (rsciio test data, GMS 2.31).
2. Two real public 4D + EDX pairs exist on a Talos/K2 or Talos/Merlin, each as TWO files linked only by an identical scan grid (section 2).
3. Nothing public is a STEMx "STEM SI" file with a Diffraction SI and an EDS SI. Section 4 is therefore inference built on measured pieces.

## 1. GMS EDS in a .dm4/.dm3
**1a. Real GMS EDS spectrum, VERIFIED.** `References/rosettasciio/rsciio/tests/data/digitalmicrograph/1D/test-EDS_spectrum.dm3` (350 KB, in repo, tags dumped with rsciio DigitalMicrographReader). GMS 2.31.734 (`GMS Version.Created`), microscope "FEI Tecnai Remote", Titan, 200 kV. Two ImageList objects: thumbnail ("Image Of EDS Spectrum", RGBA DataType 23, 384x207) and **"EDS Spectrum"**: DataType 11 (uint32), Dimensions [4096], PixelDepth 4, Brightness Units "Counts", Dimension.0 Origin 95.6, Scale 0.005, Units "keV" (so energy of channel i = (i-95.6)*0.005 keV; offset -0.478 keV; rsciio does offset = -Origin*Scale, `_api.py:470-474`).
Tags under ImageTags (VERIFIED):
- `Meta Data.Format = "Spectrum"`, `Meta Data.Signal = "X-ray"`, `Meta Data.Acquisition Mode = "Parallel dispersive"`.
- `EDS.Acquisition.{Channels 4096, Dispersion (eV) 5.0, Exposure (s) 60.0, Date '8/8/2016', Start time, End time, Continuous Mode 'single spectrum', Count Rate Unit, Energy Cutoff (V), LiveTime multiplier 1.0, SI.Do differential 0}`.
- `EDS.Detector Info.{Azimuthal angle 45.0, Elevation angle 18.0, Solid angle 0.7, Incidence angle 90.0, Stage tilt 0.0, Detector type 'SIUTW', Dead layer, Active layer, Gold layer, Window thickness, Window type 0, Fano 0.1, Zero fwhm 0.08}`.
- `EDS.Live time = 3.806`, `EDS.Real time = 4.233` (seconds, one value per spectrum), `EDS.Count rate = 431.0`.
- `EDS.Spectrometer Meta Data.Data` (5890-byte XML blob, uint8 array) + `.Size`. The XML is a **Bruker ESPRIT TRTSpectrum** header with `<Type>SuperX</Type>`, `RealTime`/`LifeTime` in ms, `ZeroPeakPosition 96`: so this file is a Super-X driven through Bruker/ESPRIT by GMS. Same chain as the owner's planned Talos G1 route (gms.md EDSIG notes).
- `Microscope Info.*` (Voltage 200000.0, Formatted Voltage '200kV', Illumination Mode 'STEM NANOPROBE', STEM Camera Length, Stage Position.*).
rsciio reads (all VERIFIED, `_api.py:1073-1103`): General date/time from `EDS.Acquisition.Date/Start time`; azimuth, elevation, solid angle, live_time, real_time from the EDS group. Beam energy comes from `Microscope Info.Voltage`. Test `test_read_EDS_metadata` expects 45.0, 18.0, live 3.806, real 4.233.
**1b. EDS SI object (3D) in .dm4: INFERRED, never seen.** rsciio treats `Meta Data.Format == "Spectrum image"` with 3 dims as a spectrum image (`to_spectrum`, `_api.py:545`), and signal_type from `Meta Data.Signal == "X-ray"` (:603). The owner's EELS SI (134) is the measured template: float32 (DataType 2), dims fastest-first [206,337,2048], axis 3 carries the energy calibration; memory order has energy slowest (rsciio reverses and transposes). By analogy: EDS SI = [nx, ny, nch], units [nm, nm, keV], energy slowest. GUESS: dtype (single spectrum is uint32; the SI may be uint32, uint16 or float32), per-pixel live time (no evidence either way; EDS.Live time is a scalar in the 1D file, and the owner's EELS file does store per-pixel side arrays such as Saturation fraction, gms.md), and whether the EDS SI object name is "EDS SI", "X-ray SI" or "EDS Spectrum Image".
**1c. Same file or separate?** UNKNOWN for the owner's STEMx. WEB: Gatan says STEMx 4D + EDS is simultaneous (Gorji slide, STEMx manual lines ~131, 240-244). The owner's EELS file proves the SI tool writes every signal into one .dm4 under one `Experiment ID`; same file is the most likely outcome, but the real Super-X path (EDS Remote Server + Bruker card) might write a separate EDS document. Mark as open.

## 4. Simulator spec
### 4a. GMS same-file .dm4 (DM4, little-endian, 16-bit tag groups as in the owner files; reuse DM4Experiment's tag walker conventions)
One run, one `Experiment ID` string, e.g. "Spectrum Imaging_10/05/2026_10:00:00 AM" (format from the owner's 036: `Meta Data.Experiment keywords`). Objects, in this order (order seen in 134/036 = thumbnail, survey, scan signal, then SI objects; GUESS that EDS comes last):
0. Thumbnail: DataType 23 (RGBA), dims [278,384], no Meta Data group. VERIFIED shape from 036.
1. `ADF Image (SI Survey)`: DataType 10 (uint16), dims [1024,1024], axes nm (scale 1.781 in 036), `Meta Data.Experiment keywords.2.Label = "Survey"`, `Meta Data.Experiment ID`, `Survey Image.Unique Image ID` (tag path `ImageTags.Survey Image.Unique Image ID`), `ImageList.N.UniqueID.1..4` int32 x4. VERIFIED (laneB).
2. `HAADF Image` (scan grid): DataType 2 (float32), dims [nx,ny] (206x337 in 134), nm axes, Label "Scan Signal", `SI.Acquisition.Survey Image.{Spectrum Image Rect, Unique Image ID}` (rect = (top,left,bottom,right) survey pixels; its aspect must equal nx/ny; VERIFIED 134). Not present in 036 (4D-only): GUESS that STEMx 4D + EDS also writes it.
3. `Diffraction SI`: DataType 2 (float32; the owner's are float32 even though K2/Merlin counts are integers; VERIFIED), dims [qx,qy,nx,ny] (036: [512,512,106,153]), axes 1/nm,1/nm,nm,nm (scale q 0.0730, scan 5.910 nm), `Meta Data.Format = "Diffraction image"`, Label "Diffraction", `Meta Data.Data Order Swapped = 1` (present in owner files, meaning unknown), `SI.Acquisition.Survey Image.*` as in 2, `Acquisition.Device.*` (GIF). VERIFIED.
4. `EDS SI` (GUESS name): DataType 11 (uint32; GUESS, alternative float32 as in EELS SI), dims [nx,ny,nch] with nch 2048 or 4096, axes [nm, nm, keV]; energy axis Origin = 0.478/0.005 = 95.6 style, Scale 0.005 keV (5 eV/ch) (VERIFIED in 1D file; Super-X G1 via ESPRIT, 4096 ch GUESS; owner may use 2048 ch at 10 eV), Brightness Units "Counts". `Meta Data.Format = "Spectrum image"`, `Meta Data.Signal = "X-ray"`, `Meta Data.Acquisition Mode = "Parallel dispersive"`, Experiment Label "EDS" (GUESS), `SI.Acquisition.Survey Image.*`, `EDS.Acquisition.{Channels, Dispersion (eV), Exposure (s), Date, Start time, End time}`, `EDS.Detector Info.{Azimuthal angle, Elevation angle, Solid angle, Detector type 'SuperX', Stage tilt, Incidence angle}` (Super-X G1 nominal: solid angle 0.7 sr as in the Titan file; elevation 18 deg, azimuth 45 deg are the file's values, real Talos values GUESS), `EDS.Live time`, `EDS.Real time` as per-SI scalars (seconds, GUESS: = dwell*nx*ny*(1-dead time)), optional `EDS.Spectrometer Meta Data.{Data,Size}` (omit or small XML), `Microscope Info.{Voltage 200000.0, STEM Camera Length, Illumination Mode, Stage Position.*}`.
Parser decisions this tests: the 4D object is chosen by Format "Diffraction image", the EDS object by Signal "X-ray"; scan grid identity: EDS [nx,ny] == Diffraction [..,nx,ny] == scan HAADF; rect aspect matches.
### 4b. Second container (no DM4): two hspy-style HDF5 files, mirroring real data A/B
`sim_EDS.hspy`: `/Experiments/__unnamed__/data` (ny,nx,nch) uint32 gzip; `axis-0` y (size ny, scale/offset in nm), `axis-1` x, `axis-2` Energy (offset 0 or -0.478 keV, scale 0.005 keV; VERIFIED real files use eV with offset 0 and scale 5-10); `metadata/Signal {signal_type EDS_TEM, binned True}`; `metadata/Acquisition_instrument/TEM {beam_energy 200, acquisition_mode STEM}`, `.../Detector/EDS {azimuth_angle, elevation_angle, live_time, real_time}`, optional `.../Detector/Camera/exposure` (dwell). `sim_4D.hspy`: `data` (ny,nx,ky,kx) int32 or float32 gzip chunked (1,3,ky,kx), axes as in A (no metadata required). Link: identical (ny,nx) and pixel size; nothing else. A single-file variant: `/eds`, `/diffraction`, `/survey` groups plus `/scan/rect` in one HDF5 (GUESS, for tests only).
