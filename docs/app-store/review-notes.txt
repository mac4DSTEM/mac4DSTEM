Notes for App Review

mac4DSTEM analyses 4D-STEM datasets from electron microscopes. You do not need a dataset of your own to try it.

How to try it:
1. Launch the app. The welcome window opens.
2. Click "Try Demo Data". It opens a small synthetic 4D-STEM dataset built into the app; every workspace works on it, and nothing on disk is touched.
3. Work down the sidebar: Prepare (calibration), Imaging (move the detector on the diffraction pattern and the virtual image updates), Bragg Disks, Crystal Maps, Reconstruction, Results.

The Spectroscopy workspace stays unavailable on the demo: it opens only when the window holds an EDS spectrum image, which needs a microscope file.

Materials Project (optional):
In Crystal Maps, the phase picker has a "Materials Project…" button that fetches a crystal structure from api.materialsproject.org. It needs the user's own free Materials Project API key, which the user types and the app stores in the macOS Keychain. It is optional: a structure can also come from a CIF file through "Import CIF…", and the rest of the app works without either. This is the app's only network request, and it is made only when the user starts it.

Agent access (com.apple.security.network.server): mac4DSTEM uses this entitlement for one feature. It is off by default. When the person turns it on, mac4DSTEM opens a listening socket (Network.framework NWListener) on this Mac's loopback address, 127.0.0.1, port 47811. It answers incoming Model Context Protocol requests over HTTP from an AI assistant the person runs on the same Mac (for example Claude Code), so the assistant can read what mac4DSTEM's windows show. The sandbox refuses the listener without this entitlement. It answers only requests that carry the token shown in that pane and refuses requests from web pages. It is not reachable from other computers. The app itself sends nothing anywhere through it. What the assistant does with what it reads is governed by that assistant and its provider.

To see the listener:
1. Choose mac4DSTEM > Settings… and open Agents.
2. Turn on the switch. Status shows "On (port 47811)".
3. Click Copy Connection Command. The copied line contains the access token.
4. In Terminal, run: curl -H "Authorization: Bearer TOKEN" http://127.0.0.1:47811/v1 (replace TOKEN with the token from the copied line). mac4DSTEM answers with its name and the list of its agent tools.
Turn the switch off and the port closes.

No account, sign-in or purchase is needed anywhere in the app.
