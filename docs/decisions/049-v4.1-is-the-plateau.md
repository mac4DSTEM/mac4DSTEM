# 049 — v4.1 is the plateau: a feature freeze with an exit checklist

Dates: 2026-09-30

Status: **accepted** (owner, 2026-09-30: "i want to find a plateau where after polishing there is a complete app and not
a construction site for more and more features … bring home v4.1 in the next sessions. i need to do some actual
scientific work after that with it").

## Decision

**The feature list is frozen at what v4.0.0 ships.** v4.1.0 is that app, finished: nothing new is started until it is
released. The model is the consolidation plan (`archive/consolidation-plan.md`, exited 2026-09-11) — a freeze with a
checklist, not a date.

**Frozen until the owner reopens them (no session picks these up):** ROADMAP parity themes 2–7, EDX correlation, live
acquisition, the lineage graph, point-group coverage beyond cubic and hexagonal, volumetric density, β″ orientation maps.
They stay written down in `ROADMAP.md` under "After v4.1"; none is a debt.

**Each half-built lane is finished or taken out, one session each — never left half-built:**
- In-app training (C5): the 500-step run and Train Model… driven, or the entry point is hidden.
- Parallax and single-slice ptychography: the cost Gate D on real data, then kept or removed (ADR 048's rule).
- Phase mapping: stays badged unvalidated (CLAUDE.md); it is not called validated to reach the exit.
- The 28 GB parity run is verification of shipped code, not a feature: it stays.

**The external review is the last intake.** Its part A findings (read-only, may run in the cloud) are each fixed or
declined by the owner in one sitting, together with the Board's 18 cards. After that sitting `open-items.md` may only
shrink: a new finding is fixed if it is a defect in a shipped feature, and otherwise goes to "After v4.1" unworked.

**Exit — v4.1.0 is released when all five hold:**
1. `tools/run-tests.sh all` green on the release commit, unit count reconciled by method name.
2. The "Unverified on screen" row of `docs/status.md` is empty.
3. `open-items.md` holds no defect in a shipped feature; what remains is a named limit or an "After v4.1" line.
4. Every half-built lane above is finished or removed, and the owner's cards are decided.
5. The owner has run one real analysis of his own end to end in the release build.

## Why

The process finds real residuals every night (refuters, Gate D), so the list never reaches zero by itself; the queue
behind each finished item was new surface. A line has to be drawn, and the owner needs the app for science more than
he needs its next feature. The freeze is reversible: reopening a theme is one sentence from him.
