# Shipping v2.5.0 and v2.5.1 — 2026-09-04

The standing plan `docs/status.md` carried into release night, kept verbatim
because its two self-corrections are the useful part, plus what actually
happened. Both releases shipped the same evening; `CHANGELOG.md` is the record
of what is in them.

## What the plan got wrong about itself

Its item 5 said `LSMinimumSystemVersion` "exists nowhere". It does —
`GENERATE_INFOPLIST_FILE` derives it from `MACOSX_DEPLOYMENT_TARGET` and
`tools/package-test/run.sh` asserts it. Stale was the VALUE, not the key.

It predicted the Liquid Glass / within-window material work would be where a
lower macOS floor bit. It was not: exactly two cosmetic symbols stood above the
floor, `ToolbarSpacer` and `.pointerStyle`, and macOS 14 was reached the same
evening.

It chose a reduced gate because disk was short. The owner freed the disk and
called for the full one, which then EXITED 1 on a real pre-existing defect —
so v2.5.0 shipped on the reduced gate after all, and said so in its notes.

notary submissions, each usually 5–15 min. Credentials verified present
2026-09-04: cert `Developer ID Application: Paul Lobpreis (3B8SMSSAX4)` and
the working `mac4dstem-notary` keychain profile. The owner tests the DMG on a
